# khial-abaya
Khial Abaya — Arabic RTL fashion store with WhatsApp ordering and secure admin dashboard.
# خيال للعبايات | Khial Abaya

متجر إلكتروني عربي بتصميم RTL وطلبات عبر واتساب.

## المميزات
- واجهة متجر متجاوبة.
- عرض المنتجات والبحث عنها.
- تفاصيل كل منتج.
- تجهيز الطلب عبر واتساب.
- لوحة إدارة محمية.
- إضافة المنتجات وتعديلها وحذفها.
- إدارة الأسعار والألوان والمقاسات والمخزون.
- حفظ المنتجات باستخدام Netlify Blobs.

## إعداد Netlify
Build command: اتركه فارغًا.
Publish directory: .

## متغيرات البيئة المطلوبة

ADMIN_PASSWORD
SESSION_SECRET
WHATSAPP_NUMBER

ADMIN_PASSWORD:
كلمة مرور قوية لا تقل عن 12 حرفًا.

SESSION_SECRET:
قيمة عشوائية سرية لا تقل عن 32 حرفًا.

WHATSAPP_NUMBER:
رقم واتساب بصيغة دولية، أرقام فقط، دون علامة +.

## الصفحات
/          المتجر
/admin.html لوحة الإدارة

## تنبيه
المنتجات الأولية تجريبية وليست منتجات حقيقية للبراند.

لا تنشر الشعار أو صور المنتجات أو رقم التواصل دون موافقة صاحب البراند.

الطلبات تُرسل عبر واتساب، ولا توجد مدفوعات إلكترونية داخل الموقع.
